按身份查看资格与流程

校荐生

普通应届专科毕业生

综测排名前60%，或符合规定的指定赛事获奖条件，由生源高校审核、公示与报送。

流程：核对学校综测方案和公示名单 → 确认资格 → 网上报名 → 统考 → 填报志愿。

自荐生

未获得校荐资格的普通应届专科毕业生

先参加目标高校相应专业测试，通过后获得该校该专业自荐资格。

流程：查专业对应目录 → 报名高校测试 → 测试合格并公示 → 统考报名和考试 → 填报获资格的专业与院校。

建档立卡家庭考生

经认定、符合相应条件的普通应届专科毕业生

需要提交资格申请并完成审核，不是仅凭个人填写家庭情况。

流程：向生源高校申请 → 审核、公示 → 报名统考 → 按符合条件的批次填报志愿。

退役大学生士兵

入伍地、退役与专科学历等条件均须核对

符合条件的往届生可申请；免文化统考，不等于所有情况都免高校考查。不得与全省统一考试专升本兼报。

流程：资格申请并选对应专业 → 审核、公示 → 选高校 → 按校方方案参加考查或录取 → 必要时征集、调剂。

大赛保送生

符合指定高等级竞赛获奖条件的应届专科毕业生

不能将一般赛事获奖当作保送资格。需由目标高校审核、综合考核和公示。

流程：向1所高校申请相关专业 → 审核与考核 → 公示获得资格 → 完成规定的网上报名手续。

3＋2转段

原本就在对口贯通培养项目中的学生

这是既定培养项目的转段，不是普通毕业生临时加入的报考身份。

流程：核对原培养项目资格 → 查当年转段要求 → 按规定完成报名及测试。

开场 · 专升本怎么报名？

专升本怎么报名？

统考科目 · 普通统考：四门公共基础课

退役士兵免试和大赛保送，不参加这四门统考。校荐、自荐和建档立卡考生，要考英语、计算机、大学语文和高等数学。每门一百分，总分四百分。

校荐生 · 方式一：综测排名

校荐生，第一种方式看综测，同年级、同专业前百分之六十。学校核算、公示和报送名单，你要核对公示名单，有异议就在公示期内及时向学校反映。

校荐生 · 方式二：指定赛事获奖

第二种方式，是通过指定赛事获奖申请校荐资格。省级及以上职业院校技能大赛，或者山东省师范类高校学生从业技能大赛，三等奖及以上，包含三等奖。要主动向专科学校申请，并提交获奖证明。

自荐生 · 先参加目标高校专业测试

自荐生，二月二十五日前按目标高校要求报名，二月二十八日到三月六日参加校测。各校时间和方式不同，可以安排考多所，但别撞场。校测合格后，就可以报名省统考了。通过哪所学校、哪个专业的校测，就只能报对应的学校和专业。

建档立卡 · 外省认定的材料要求

建档立卡家庭考生，一月十二日前向就读的专科学校申请。建档立卡地在外省的，要提交相关系统截图，并加盖县级农业农村部门公章。

建档立卡 · 两个批次，按条件填报

仍然考四门统考。二零二六年专项资格线九十分，达到一百二十分，还能填校荐批次，不用另外取得校荐资格。专项先录，没录取再按规定走校荐批次。

退役士兵 · 看入伍地，不只看户籍

退役大学生士兵，先看入伍地是不是山东。符合条件的往届生也能报；已经被免试专升本录取过的，不能再报。

退役士兵 · 资格申请 → 选专业 → 选高校

四月一日到二日申请审核，选一个对应专业；四月十七日选一所高校。应届生的学籍证明，由就读的专科学校提前开具。免试和普通统考，不能兼报。

退役士兵 · 免文化课，不等于人人不用考

人数不超过计划，按规定全额录取；超过计划，才组织综合考查。符合三等功及以上相关条件的，免考查。首轮没录取，四月二十九日还有征集机会。

大赛保送 · 不是所有国赛奖都能保送

大赛保送，要核对指定奖项：国家队选手世界技能大赛获奖，世界职业院校技能大赛总决赛争夺赛金奖，或者原全国职业院校技能大赛一等奖。

大赛保送 · 只向1所高校申请

二月二十五日前，只向一所高校申请相关专业。经过审核、综合考核和公示，才能取得资格。综合考核免技能考核，取得资格后不参加省统考，也不能再用其他身份报名。

共同时间 · 统考报名与考试，分清两个时间

最后把时间记住：校荐、自荐、建档，三月十一日到十三日报名缴费，三月二十八日到二十九日统考。保送生也要在报名期间完成注册、照片和信息填写。

最后提醒 · 过资格线，不代表已经录取

七十个志愿，指的是专业加院校的组合，不是七十所学校。通过资格线，也不等于一定录取。材料细节和更多时间节点，放在配套文字里，报考前再核对。
